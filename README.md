# رِفقة

رِفقة هو نموذج أولي لبوت تيليغرام عربي يساعد الطلاب على العثور على شركاء دراسة متوافقين، مع الإبقاء على صفحة المنتج التعريفية الحالية.

## المتطلبات

- Node.js 20 أو أحدث.
- حساب تيليغرام.

## إنشاء البوت عبر BotFather

1. افتح المحادثة الرسمية مع `@BotFather` في تيليغرام.
2. أرسل الأمر `/newbot` واتبع التعليمات لاختيار الاسم واسم المستخدم.
3. انسخ رمز الوصول الذي يرسله BotFather، ولا تشاركه أو تحفظه داخل Git.

## الإعداد المحلي

```bash
npm install
cp .env.example .env
```

افتح `.env` وضع الرمز بعد اسم المتغير:

```dotenv
TELEGRAM_BOT_TOKEN=ضع_رمز_BotFather_هنا
```

ملف `.env` مستثنى من Git. لتشغيل البوت:

```bash
npm start
```

ثم افتح البوت في تيليغرام وأرسل `/start`. يمكن إلغاء إدخال الملف باستخدام `/cancel`، وإعادة البحث لاحقاً باستخدام `/matches`.

## ربط زر الموقع بالبوت

بعد اختيار اسم مستخدم البوت، غيّر قيمة `TELEGRAM_BOT_URL` مرة واحدة فقط في `script.js`. لا حاجة لتعديل HTML.

لتشغيل صفحة الموقع محلياً:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## آلية المطابقة الحالية

يمنح النظام نقاطاً للتخصص نفسه أو ذي الكلمات المشتركة (25%)، والسنة الدراسية (15%)، والمواد المشتركة (20%)، والأيام والأوقات المتداخلة (15%)، وأسلوب الدراسة (15%)، ومستوى الالتزام (10%). تُرتب النتائج وتُعرض أفضل ثلاثة ملفات، من دون إظهار اسم مستخدم تيليغرام أو رقم الهاتف أو وسيلة اتصال مباشرة.

تُحفظ الملفات محلياً في `data/users.json` بطريقة كتابة ذرية. الملف مستثنى من Git لحماية بيانات الطلاب.

## الفحوصات

```bash
npm run check
npm test
TELEGRAM_BOT_TOKEN='123456:AAAAAAAAAAAAAAAAAAAAAA' npm run check:config
git diff --check
```

فحص الإعداد لا يتصل بتيليغرام ولا يطبع الرمز.

## حدود النسخة الأولية

- التخزين محلي ومناسب لعملية بوت واحدة فقط، وليس للنشر متعدد الخوادم.
- جلسة الأسئلة الحالية محفوظة في الذاكرة وتُفقد عند إعادة تشغيل البوت، بينما تبقى الملفات المكتملة محفوظة.
- لا توجد بعد موافقة متبادلة أو مشاركة آمنة لبيانات التواصل.
- تشابه التخصص والمواد يعتمد على التطبيع والكلمات المشتركة، وليس نموذج ذكاء اصطناعي دلالياً.
- يجب وضع سياسات احتفاظ وحذف وبلاغات وإدارة قبل استخدام المنتج على نطاق واسع.
