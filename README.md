# Twinny — توأمك بالدراسة

منصة عربية تساعد الطلاب في العثور على شريك دراسة مناسب حسب التخصص، الجدول، وأسلوب التعلّم، مع بوت تيليغرام يحافظ على خصوصية الاسم الحقيقي.

## التشغيل

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`.

## تشغيل البوت

1. أنشئ مشروعاً في Supabase وشغّل محتوى `supabase/schema.sql` من SQL Editor. عند كل تحديث للميزات، شغّله مرة أخرى بأمان لإضافة الأعمدة الجديدة مثل الدولة وقوائم الدراسة.
2. انسخ `.env.example` إلى `.env` وأضف Token البوت ومفاتيح Supabase.
3. ثبّت الحزم وشغّل البوت:

```bash
npm install
npm start
```

البوت يستخدم long polling؛ لذلك يشتغل على Render أو Railway بدون إعداد Webhook أو دومين في النسخة الأولى.

### تحسين المطابقة بالذكاء الاصطناعي

أضف `GROQ_API_KEY` إلى ملف `.env` وRender لتفعيل إعادة ترتيب المرشحين عند البحث فقط. يبقى الجنس وبقية الفلاتر الأساسية مفروضة في الكود، ولا تُرسل الأسماء الحقيقية أو معرفات تيليغرام أو الرسائل إلى Groq. يدخل بالتوافق جدول الأيام والأوقات المتاحة، التخصص والمرحلة، التفضيلات، ومؤشر الالتزام المجمّع من الجلسات والمهام والتقييمات.

### مساحة الدراسة المشتركة

بعد قبول الشراكة، يوفر البوت جلسات 25 أو 50 دقيقة بموافقة الطرفين، ملخص إنجاز بعد الجلسة، مهام مشتركة، زر «جاهز أدرس هسة»، تذكيرات حضور بتوقيت بغداد، streak، وتقرير أسبوعي تلقائي مساء الجمعة. شغّل `supabase/schema.sql` مرة أخرى في Supabase SQL Editor بعد التحديث لإضافة جداول الجلسات والتذكيرات والتقييمات.

## النشر على Render

يوجد ملف `render.yaml` جاهز. ارفع المشروع إلى GitHub، ثم من Render اختر **New → Blueprint** واربط المستودع. أضف القيم السرية التالية عند إنشاء الخدمة: `BOT_TOKEN` و`SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY`.

تستخدم هذه النسخة خدمة Render المجانية. بعد النشر، أنشئ Cron خارجي يطلب مسار `/health` كل 10 دقائق حتى تبقى الخدمة نشطة.
